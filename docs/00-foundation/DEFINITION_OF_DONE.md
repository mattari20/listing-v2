# Definition of Done

A step is complete only when all applicable conditions are true:

- Its requirement and acceptance criteria are documented.
- Implementation matches approved scope.
- Relevant automated tests are added/updated and pass.
- Required CI checks pass on the latest PR head SHA.
- Security, privacy, accessibility and data-quality implications are addressed.
- Documentation and traceability are updated.
- PR is merged under approved repository policy, or a documented exception explains why not.
- Merged commit and evidence are recorded.
- Step progress and milestone progress are recalculated.
- Master controller names the next eligible step.

A milestone additionally requires all mandatory step acceptance criteria, no unresolved release-blocking defects, evidence review and explicit milestone closeout record.

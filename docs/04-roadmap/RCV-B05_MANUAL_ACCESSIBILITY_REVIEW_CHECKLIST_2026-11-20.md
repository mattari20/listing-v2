# RCV-B05 — Manual Accessibility Review Checklist

**Status:** NOT PERFORMED  
**Purpose:** Record future human review evidence. This checklist is not a certification or conformance statement.

| Review area | Manual check | Status | Evidence / notes |
|---|---|---|---|
| Keyboard-only | Operate language switch, search, every filter, shortlist add/remove, profile navigation, comparison region and pagination without a pointer | NOT PERFORMED | |
| Focus visibility | Confirm visible focus indicator on every interactive element in English/LTR and Urdu/RTL; ensure focus is not obscured | NOT PERFORMED | |
| Screen reader | Review landmarks, page titles, heading order, labels, fieldset/legend, error summary, status messages and comparison table relationships with a screen reader | NOT PERFORMED | |
| 200% zoom | Confirm no loss of content or function at 200% zoom on search, profile and comparison pages | NOT PERFORMED | |
| Reflow | Confirm narrow viewport reflow; verify comparison's labelled horizontal scrolling remains usable for two-dimensional content | NOT PERFORMED | |
| Contrast | Measure text, links, controls, focus, notices, active-filter state and disabled controls against WCAG contrast criteria | NOT PERFORMED | |
| RTL behavior | Check navigation, form labels/controls, filter groups, profile facts, comparison table and keyboard focus order in Urdu | NOT PERFORMED | |
| Mixed direction | Check Urdu UI with English names, URLs, numerals and source-language facts; confirm no punctuation/order corruption | NOT PERFORMED | |
| Browser/device | Check representative desktop and mobile browser combinations | NOT PERFORMED | |

A qualified accessibility reviewer must record findings and remediation evidence before any WCAG conformance claim. No such reviewer is appointed by this repository change.

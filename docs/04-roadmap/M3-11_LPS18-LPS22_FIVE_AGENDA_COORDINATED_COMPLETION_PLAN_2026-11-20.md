## Execution protocol

For each agenda:
1. Confirm current `main` SHA and inspect only required repository documents.
2. Define exact agenda scope, deliverable, dependencies and stop conditions.
3. Create a branch from verified `main`; author the agenda report and update the relevant progress, catalog, master plan, gap register and evidence intake records.
4. Create a PR with explicit non-authorization and non-promotion statements.
5. Run exact-head foundation CI and documentation validation; require both to pass.
6. Merge only after exact-head checks pass and mergeability is confirmed; use expected head SHA.
7. Verify merge commit equals `main`, then fetch and verify every changed file.
8. Record the result and only then begin the next agenda.

No agenda is considered complete until its repository record is merged and exact-main verification is complete. If CI fails, mergeability is false, evidence is missing or scope would cross the boundary, stop and resolve within the same authorized scope.
